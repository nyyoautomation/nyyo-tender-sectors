Free installation kit — local version (option)

Option

The default offer is online first, isolated workspace, AI in Europe; local version as an option. This page covers the optional local version, which is mainly useful for sensitive contracts such as protected sites or security.

What the free kit contains

  • A prerequisites checklist: office PC or mini-PC, memory, disk space, operating system.
  • How to check the installer yourself with its SHA-256 checksum: certutil -hashfile installer SHA256 on Windows, shasum -a 256 installer on macOS.
  • A step-by-step installation guide and a checklist for the first launch.

About the local version

  • Built to run offline: your tenders, prices and past files stay on your own computer.
  • Local AI (Ollama with an open model such as Mistral or Qwen).
  • No remote-access feature. You download updates yourself, whenever you choose.
  • Your IT person can review the source code. The delivered build comes with OS code signing.

Installation while you watch

Done on site, or by video call with you sharing your screen. We never ask for a password and never take control of your computer.
